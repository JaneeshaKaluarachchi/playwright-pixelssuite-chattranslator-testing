## 📌 Project Overview

This project focuses on testing the **accuracy of transliteration** from chat-style Singlish to Sinhala using the following system:

🔗 https://www.pixelssuite.com/chat-translator

The objective is to identify **50 negative test cases** where the system fails to correctly convert Singlish input into Sinhala output.

---

## 🎯 Objectives

* Identify **50 failed transliteration scenarios**
* Cover **24 Singlish input types** (minimum 2 test cases each)
* Automate testing using **Playwright (Python)**
* Compare expected vs actual output
* Mark test results as **PASS / FAIL**

---

## ⚙️ Setup Instructions

### 1. Clone the Repository

```bash
git clone https://github.com/JaneeshaKaluarachchi/playwright-pixelssuite-chattranslator-testing
cd IT23858848
```

### 2. Create Virtual Environment

```bash
py -3.13 -m venv venv
venv\Scripts\activate
```

### 3. Install Dependencies

```bash
pip install playwright openpyxl
python -m playwright install
```

---

## ▶️ How to Run the Automation Script

```bash
python test_automation.py --excel "IT23858848/IT23858848_test_cases.xlsx" --url "https://www.pixelssuite.com/chat-translator"
```

### Optional Parameters:

* `--wait-ms 5000` → Wait time for page load
* `--type-delay-ms 80` → Typing delay
* `--slow-mo-ms 200` → Slow motion for debugging

## 🧪 Testing Approach

* Manual identification of incorrect transliterations
* Creation of expected Sinhala outputs
* Automation using Playwright to:

  * Input Singlish text
  * Capture output
  * Compare with expected result
* Mark results automatically
